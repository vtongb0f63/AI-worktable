# 生长：开发技术栈报告

网站前端采用 **Next.js 16.3.6、React 19.3、TypeScript 和 Tailwind CSS 4**。登录后的工作台使用客户端交互；公开主页由 Next.js 服务端获取数据并渲染，SVG 绘制成长树和发芽动画。

后端采用 **Python 3.12+、FastAPI 和 Pydantic**，以 REST API 提供身份验证、目标管理、进度、公开主页和 AI 建议。数据存储在 **SQLite**；密码使用 Argon2 哈希，用户提供的 AI 密钥用 Fernet 加密。公开接口通过字段白名单和逐级可见性检查，避免返回私有内容。

服务部署在 **AlmaLinux 9 VPS**，由 **Docker Compose** 运行 API、网页和 **Caddy**；Caddy 提供 HTTPS 与反向代理。GitHub Actions 运行 Python 测试及前端类型检查、构建，并将镜像发布到 GHCR。验证邮件通过 Resend SMTP 发送，AI 建议通过用户自己的 DeepSeek API Key 调用。
