# 生长：网站功能介绍

生长是一个把长期目标落实到每周、每天的个人成长网站。用户从“四年愿景”开始，依次建立学年、学期、月、周和日任务；目标可以调整层级与上级，也可以删除。任务完成后，进度按权重向上汇总，并呈现在成长树、时间线和打卡热力图中。

每周计划可选出 3–5 个重点；每日页面最多安排 3 项主任务。AI 助手可生成任务拆解和复盘草稿，只有用户确认采纳后才会保存。注册采用邀请码和邮箱验证。

用户可以逐项决定哪些目标公开。老师或其他访客**无需注册**：打开作者在“设置 → 公开主页”复制的链接即可查看，也可以在网站首页输入作者的用户名。公开页只展示主动公开的目标、日期和进度；私人备注、邮箱、复盘和 AI 密钥不会公开。
